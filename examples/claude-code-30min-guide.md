# 참고 글: Claude Code 처음 30분 가이드 (튜토리얼 카테고리)

이 글은 `blog-writer`가 **튜토리얼·가이드** 카테고리에서 모방해야 할 톤·구조 샘플.

## 학습 포인트 (후기 글과의 차이)

1. **단계 번호 명시**: "1단계 / 2단계" 또는 "처음 / 그 다음 / 마지막"으로 진행 감각 줌.
2. **결과 미리보기**: "다 따라하면 ~할 수 있게 됩니다" 첫 문단에 약속.
3. **코드/명령어 박스**: 그대로 복사할 수 있게.
4. **흔한 실수 박스**: "이런 거 막힐 수 있어요" 섹션.
5. **사진 → 스크린샷**: `📸 [어디 화면이 어떻게 보이는지]`.
6. **마무리는 다음 단계 추천**: "이거 끝나면 X 해보세요".

# 🛠 Claude Code 처음 30분 가이드

*Claude Code 시작하기 / 처음 써보는 사람용*

요즘 개발자 사이에서 Claude Code 자주 들리시죠.
"써보고 싶은데 어디서부터 손대야 하지?" 싶으셨다면 30분만 따라오시면 돼요.

이 글 끝나면
**터미널에서 Claude Code 띄우고, 내 코드 한 파일 분석시키는 것까지** 할 수 있게 됩니다.

순서는 설치 → 첫 실행 → 첫 명령 → 자주 막히는 부분 순입니다.

# 📌 시작 전 준비물

## 💻 OS
macOS / Linux / Windows (WSL)

## 🧰 필수
* Node.js 20 이상
* 터미널 다룰 수 있는 정도

## 🔑 계정
Anthropic 계정 (claude.ai 가입돼 있으면 OK)

---

# 1️⃣ 설치 — 명령어 한 줄이면 끝

터미널 열고 다음 한 줄 복사하세요.

```bash
npm install -g @anthropic-ai/claude-code
```

설치 끝나면 어디서든 `claude` 명령으로 실행됩니다.

📸 [터미널에서 npm install 진행 화면]

## ⚠️ 자주 막히는 부분
* `permission denied` 뜨면 `sudo` 붙이거나 `nvm` 사용 권장
* Node 18 이하면 동작 안 함 → `node -v`로 먼저 확인

---

# 2️⃣ 첫 실행 — 폴더 안에서 띄우기

분석하고 싶은 프로젝트 폴더로 이동한 다음 그냥 `claude` 입력하세요.

```bash
cd ~/my-project
claude
```

처음이면 로그인 창이 한 번 뜹니다.
브라우저에서 인증 끝내면 터미널이 자동으로 이어받아요.

📸 [claude 실행 직후 환영 화면]

---

# 3️⃣ 첫 명령 — 코드 한 파일 분석시키기

화면이 뜨면 그냥 자연어로 부탁하면 돼요.

```
이 폴더에 어떤 파일들 있어?
```

폴더 구조를 한 번 정리해줍니다.
다음으로 특정 파일 분석을 시켜보세요.

```
src/index.ts 읽고 무슨 역할 하는지 알려줘
```

여기까지 따라오시면 사실상 입문 끝이에요.
