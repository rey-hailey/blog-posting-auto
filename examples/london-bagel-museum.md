# 참고 글: 런던 베이글 뮤지엄 안국점 (스타일 학습용)

이 글은 `blog-writer` 에이전트가 모방해야 할 톤·구조·리듬의 기준 샘플. 새 글 생성 시 Planner가 구조 패턴을, Writer가 어미·문단 리듬을 참고.

## 학습 포인트

1. **첫 줄 3박자 훅**: "요즘 ~ 보게 되는 곳 있죠" (친숙) → "진짜 그렇게 맛있을까 궁금" (자격지움) → "결론부터 말하면 ~" (시간보장 + 결론 선공개)
2. **섹션 헤더**: 이모지 + 짧은 문장형 ("🥯 베이글 향이 진짜 미쳤어요")
3. **음식 후기 3단**: 비주얼 → 첫입·중간·끝맛 시간축 → 페어링·재방문 의지
4. **단락**: 1~3문장, 빈 줄로 구분
5. **사진 placeholder**: `📸 [한 줄 설명]`, 섹션당 1개
6. **마무리**: 총평 → 추천 대상 체크리스트 → SEO 키워드 → 해시태그
