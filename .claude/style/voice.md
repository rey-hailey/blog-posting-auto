# 말투 (voice)

이 프로젝트가 만드는 모든 블로그 글은 다음 톤을 따른다.

## 기본 원칙

- **존댓말**. `~요 / ~죠 / ~니다` 균형 사용.
- **친구한테 카페에서 설명하는 톤**. 보고서·뉴스·논문 톤 금지.
- **1인칭 경험담 OK**. "제가", "솔직히", "개인적으로" 자연스럽게 사용.
- **3박자 도입**: 친숙 미끼 → 자격지움 → 시간보장.

## 어미 분포 (한 단락 안)

같은 어미 3문장 연속 금지. 권장 분포:

| 어미 | 톤 |
|------|----|
| `~었어요 / ~았어요` | 경험 회상 |
| `~더라고요` | 발견 공유 |
| `~네요 / ~군요` | 즉각 반응 |
| `~죠 / ~잖아요` | 공감대 호소 |
| `~니다 / ~습니다` | 정리·결론 |

한 단락 안에 위 중 최소 2종 섞기.

## 첫 줄 훅 (Anna Karenina 3박자)

```
{친숙 미끼: 독자가 이미 아는 장면}.
{자격지움: 모를 수도 있다는 가능성 한 줄}.
{시간보장: 5분이면 끝난다 같은 안전감}.
```

예:

> 요즘 북촌 가면 꼭 한 번쯤 보게 되는 곳 있죠.
> 솔직히 "진짜 그렇게 맛있을까?" 의심도 됐어요.
> 다녀와봤더니, 왜 줄 서는지 5분이면 알겠더라고요.

## 단락 구성

- **1~3문장**. 4문장 이상이면 분리.
- **빈 줄로 단락 구분**. 모바일 가독성 우선.
- **첫 문장 짧게 시작**. 시각적으로 빨리 진입.

## 어절 단축

한 문장 25어절 초과 → 분리 또는 절 단축. 순우리말 우선:

| 번역투 | 권장 |
|--------|------|
| 굉장히 인상적인 경험을 했다 | 인상 깊었다 |
| ~에 대한 ~을 진행했다 | ~을 했다 |
| ~을 통해 ~을 할 수 있다 | ~으로 ~한다 |

## 결론 두 번 박치기

- **도입**: 한 줄 결론 선공개.
- **마지막 총평**: 같은 결론을 다른 표현으로 재진술.

독자가 글 중간에 이탈해도 핵심은 가져가야 함.

## 화자 옆자리 톤

- "여러분"보다 "혹시 ~해보신 적 있으세요?" 류 개별 호명.
- 강의자 톤 / 전문가 톤 금지. 같이 다녀온 친구가 알려주는 톤.
