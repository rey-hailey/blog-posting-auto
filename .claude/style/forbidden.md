# 금지 표현 (forbidden)

PreToolUse hook이 Write/Edit 직전 `forbidden.patterns` 정규식으로 자동 grep. 매치 발견 시 차단.

## 카테고리

### 1. 영어 직역체 / it·this 추상 지시어 주어
- "이 글은", "이 글이"
- "이것은 ~이다"
- "그것은 ~을 의미한다"
- "이 설계는", "이 시스템은" — 명사로 시작하는 영어 직역 주어 금지

**대안**: 가리키지 말고 바로 말한다.

### 2. AI투 / 형식적 카피
- "~에 대해 알아보겠습니다"
- "~에 대해 살펴보겠습니다"
- "본 글에서는"
- "결론적으로 말씀드리면"
- "주목할 만한 점은"
- "흥미로운 점은"

**대안**: 바로 본론.

### 3. 보고서·뉴스 톤
- "X일 X사가 X를 발표했다"
- "~에 따르면"
- "~로 알려졌다"
- 본문에 날짜 (`2026년 5월 19일` 류) 삽입 금지 — 뉴스 보도문 냄새

**대안**: 독자가 뭐가 달라지는지로 시작.

### 4. 과잉 수식·모호어
- "정말 정말", "진짜 진짜" — 1회만
- "굉장히 매우" 중첩
- "어떻게 보면"
- "어떤 의미에서는"
- "사실상" (별 의미 없을 때)

### 5. 영어 단어 남용
- "팩트체크" → 사실 확인
- "퀄리티" → 품질
- "디테일" (한국어로 잘 풀리는 맥락에서) → 세부

(단, 일반 표기인 외래어는 허용: 카페, 베이글, 브런치 등)

### 6. 모호한 지시
- "이 뭐시기"
- "그 뭐냐"
- 영어식 "it" 번역체 지시대명사

## 정규식 파일

같은 폴더 `forbidden.patterns` 참고. hook이 이 파일을 직접 사용.
