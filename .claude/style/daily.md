# 일상글 모드 (daily)

오케스트레이터가 `POST_TYPE=daily`로 분류한 글에 적용. 이 파일의 규칙이 voice.md·readability.md·checklist.md의 **구조·훅·SEO 규칙보다 우선**한다. 금지표현(forbidden.md), 사실 규칙(verified만 사용, 디테일 임의 추가 금지), 존댓말은 그대로 유지.

## 분류 기준 (오케스트레이터)

| daily (일상글) | info (정보글) |
|---|---|
| 사용자가 직접 겪은 일이 글의 중심 (병원 진료, 방문, 행사, 하루 기록, 가족 이야기) | 주제·키워드 자체를 설명·정리·비교하는 글 (증상 정리, 사용법, 제품 비교, 뉴스 정리) |
| 사용자 메모에 "~했음, ~받음, ~해서 짜증" 같은 경험 서술이 있음 | 사용자 입력이 키워드·질문 형태 |

- 경험 + 정보가 섞이면 경험이 중심일 때 daily. 정보는 이야기 속 한두 문장으로 녹인다.
- 애매하면 daily 쪽으로 기운다 (블로그 성격: 부부의 임신·일상 기록).

## 목표

**읽는 사람이 그날 장면을 따라가게 만드는 글.** 정보 전달이 아니라 이야기. 정리하고 설명하려 들지 말고, 있었던 일을 순서대로 다정하게 들려준다.

## 어조

- **다정한 존댓말**: `~했어요 / ~더라고요 / ~였죠 / ~네요`. 사용자 확정 톤.
- 화자는 블로그 주인(남편) 1인칭. 독자에게 강의하지 않는다.
- 감정은 사용자 메모에 있는 만큼만. 메모에 "짜증"이 있으면 짜증, 없으면 지어내지 않는다.
- 사용자의 원래 말맛을 살린다 (예: "고추 보여주며 성별 또 인증" → 그 유머를 살려서 다듬되 순화 과하게 하지 않기).

## 구조

- **시간 순서 서술**이 기본. 도착 → 진료 → 접종 → 귀가처럼 흐름대로.
- **소제목 0~3개**. 짧은 글(1500자 이하)은 소제목 없이 문단만으로. 소제목을 쓰면 이모지 없이 담백하게, 장면 전환 지점에만.
- **넣지 않는 것**:
  - "이런 분들께 추천해요" 섹션
  - "SEO 키워드" 섹션 (plan.md 메타에만 남기고 본문에는 넣지 않음)
  - "결론부터 말하면", "금방 읽혀요", "5분이면" 같은 3박자 훅·시간보장
  - 도입 결론 선공개 + 마지막 총평 재진술 (결론 두 번 박치기)
  - 정보 박스·표·체크리스트 (꼭 필요한 일정 하나 정도는 문장으로)
  - 섹션마다 `---` 구분선
  - "~하는 분들께 도움이 되길" 같은 마무리 인사 상투구
- **첫 문장은 장면으로 시작**. 예: "2차 정밀초음파 날이었어요." 독자 호명·질문형 미끼로 시작하지 않는다.
- **마무리는 여운 한두 문장**. 요약하지 않는다. 다음 일정(예: 한 달 뒤 임당검사)이 있으면 자연스럽게 다음 이야기로 남긴다.
- **해시태그**: 글 맨 끝 한 줄, 5~8개. 별도 헤더 없이.
- 사진 자리: `📸 [한 줄 설명]` 글 전체 0~2개.

## 문단·문장

- 문단 2~4문장 허용 (정보글의 1~3문장 규칙보다 느슨하게). 이야기가 끊기지 않게.
- 한 문장 25어절 이하는 유지.
- 같은 어미 3연속 금지는 유지.

## 정보가 섞일 때

- 사용자가 겪은 일과 직접 연결된 정보만, verified에 있는 것만 한두 문장으로.
  - 예: "임산부 독감 무료접종 기간이라 아내는 무료로 맞았어요. (질병관리청 발표 기준 내년 4월까지)" 정도.
- 별도 섹션·목록으로 빼지 않는다.
- 의학 정보가 들어가면 끝에 한 줄만: "의료 정보는 담당 병원 안내가 우선이에요." 수준. 긴 고지 박스 금지.

## Reviewer 체크 (daily)

- [ ] 추천/SEO 섹션, 3박자 훅, 결론 선공개·재진술 없음
- [ ] 소제목 3개 이하, 이모지 소제목 없음
- [ ] 시간 순서로 읽힘, 첫 문장이 장면
- [ ] 사용자 메모에 없는 장면·감정·대사 없음
- [ ] 정보는 이야기 속 문장으로만, verified 근거 있음
- [ ] 해시태그 맨 끝 한 줄 5~8개
- [ ] 금지표현 0건, 존댓말 통일
