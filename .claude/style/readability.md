# 가독성 (readability)

모바일 스크롤 환경 가정. 한 화면에 잡히는 글이 한 덩어리.

## 문장

- **한 문장 25어절 이하**. 초과 시 분리.
- 쉼표 3개 이상 → 분리 후보.
- 종속절 2단 이상 중첩 금지.

## 단락

- **1~3문장 / 단락**.
- 단락 사이 항상 빈 줄.
- 4문장 이상이면 의미 단위로 잘라낸다.

## 섹션

- **5~12개**. 12개 넘으면 통합 가능 여부 확인.
- 섹션당 하나의 메시지.
- 섹션 헤더에 이모지 1개 권장 — 스크롤 시 시각 앵커.

## 헤더 패턴

```
# {이모지} {짧은 문장형 제목}
```

예:
- `# 🥯 베이글 향이 진짜 미쳤어요`
- `# ☕ 커피 조합도 괜찮았어요`
- `# 📌 이런 분들께 추천해요`

형용사·감탄 어미로 끝나는 짧은 문장이 클릭·스크롤 유도.

## 사진 placeholder

```
📸 [한 줄 사진 설명]
```

- 섹션당 0~1개.
- 본문 흐름 끊지 않는 자리 (단락 끝).

## 리스트

- 3~7개 항목이 가장 잘 읽힘. 8개 이상이면 분류 후 2개 리스트로.
- 항목당 1~2줄. 길면 단락으로 풀어쓴다.

## URL

- 단락 끝에만 배치. 문장 중간 인라인 금지.
- 가능하면 마크다운 링크 형식 `[보기 좋은 텍스트](url)`.

## 글 전체 길이 기준

| 글 유형 | 권장 분량 (자) |
|--------|---------------|
| 짧은 후기·팁 | 800~1200 |
| 표준 블로그 글 | 1500~2500 |
| 깊은 가이드·정리 | 3000~5000 |

plan.md에 추정 분량 명시, ±20% 안에서 Writer가 채운다.
