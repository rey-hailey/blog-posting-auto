# 저장하고 싶은 글인지 확인 (checklist)

Reviewer가 final.md 확정 직전 자체 평가. 모두 PASS 못 하면 final.md 생성 보류.

## 구조 (Structure)

- [ ] 첫 줄 친숙 미끼 + 자격지움 + 시간보장 3박자 있다
- [ ] 도입에 한 줄 결론 선공개 있다
- [ ] 섹션 5~12개, 각 섹션 메시지 1개
- [ ] 마지막 총평에 결론 재진술 있다
- [ ] "이런 분들께 추천" + "SEO 키워드" + "해시태그" 섹션 있다

## 톤 (Tone)

- [ ] 존댓말 통일, 어미 분포 다양 (한 단락 안 같은 어미 3연속 없음)
- [ ] 보고서/뉴스 톤 없음
- [ ] 1인칭 경험담 자연스러움
- [ ] 영어 직역체 / it·this 추상 주어 없음

## 가독성 (Readability)

- [ ] 모든 단락 1~3문장
- [ ] 모든 문장 25어절 이하
- [ ] 단락 사이 빈 줄
- [ ] 섹션 헤더 이모지 1개 + 짧은 문장형

## 사실 (Facts)

- [ ] 모든 수치·고유명사·인용 research.md에 근거 있음
- [ ] 출처 없는 단정 없음 (근거 약하면 약화 표현으로)
- [ ] 본문에 날짜 (X월 X일) 박힌 곳 없음

## 금지 표현 (Forbidden)

- [ ] `forbidden.patterns` grep 결과 0건
- [ ] AI투 / 형식적 카피 없음
- [ ] 영어 단어 불필요 사용 없음

## SEO / 메타

- [ ] 제목에 메인 키워드 포함
- [ ] 본문에 메인 키워드 2~3회 자연 등장 — **정량 측정 필수**:
      ```bash
      MAIN_KW="<plan.md SEO 키워드 1번>"
      grep -c "$MAIN_KW" workspace/{RUN_ID}/final.md
      # 결과 2~5회 권장. 0 또는 1이면 부족, 6+면 키워드 스터핑 의심.
      ```
- [ ] SEO 키워드 3~7개, 해시태그 8~14개 — 카운트 확인:
      ```bash
      awk '/^# 🔍 SEO/,/^# #️⃣/' workspace/{RUN_ID}/final.md | grep -c '^\* '
      awk '/^# #️⃣/,EOF' workspace/{RUN_ID}/final.md | grep -oE '#[가-힣A-Za-z0-9]+' | wc -l
      ```

## 사진

- [ ] 사진 placeholder 섹션당 1개 이하
- [ ] 사진 설명 한 줄, 본문과 연결됨

## 발행 가능성

- [ ] **솔직 평가**: "저장하고 싶은 글인가?"  
       만약 "아니"면 → Writer 재호출 결정 (Reviewer 단독 PASS 금지)
